# Issue 40 selector mock decision

Open each HTML file directly in a browser. Each shows a desktop frame and a 390px phone frame. These are static design studies, not working controls.

## Owner question

Which selector should preview click and press effects in the homepage particle field: **A**, the compact disclosure with a native select; **B**, the always visible segmented rail; or **C**, the phone sheet? The owner cannot answer during this run, so this remains unanswered. Each mock compares Off, Shockwave, Gravity well, Vortex, Particle scatter, Press → gather → release, and Local turbulence. Gravity well shows short implosion and slow pull as possible tunings.

## Recommendation for the preview

Use **A** as the provisional direction. It preserves more of the current hero and its calls to action, uses a native select that already handles small screens and keyboard input, and makes Off explicit. Its small footprint and simple markup make it the safest choice to revise after the owner responds. B gives the preview feature substantial visual weight on every screen. C needs a modal sheet interaction, focus handling, and a separate desktop pattern.
