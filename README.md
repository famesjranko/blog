# Blog

Personal website for essays and writing.

## Development

```bash
make install
make preview
make check
```

## Stack

* TypeScript
* Zod
* Markdown
* Biome
* Vitest
* GitHub Actions
* GitHub Pages

## Structure

```text
content/    Markdown content
src/        Site generator
styles/     Stylesheets
static/     Static assets
scripts/    Repository tooling
dist/       Generated site output
```

## Deployment

The site is intended for:

```text
https://famesjranko.github.io/blog/
```

Deployment is currently manual.
